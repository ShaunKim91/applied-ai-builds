## The one real bug found and fixed this build (two manifestations)

See `../debug/issue-01-quoted-string-arguments-broke-tool-lookups.md` for the full write-up, found
via manual (Playwright) screenshot inspection of the History page's real search results:

1. **Manifestation 1**: the model called `lookup_claims_procedure("subrogation")` — quotes included,
   following ordinary function-call syntax. The tool's own keyword matching stripped whitespace but
   not quote characters, so a real, existing procedure ("subrogation checklist") was reported as not
   found.
2. **Manifestation 2**, found while verifying the first fix: an initial fix (stripping quotes from
   the whole raw argument string before splitting) handled Manifestation 1 but broke a *second* real
   case — `check_filing_deadline("Belmont Bay", "2025-01-01")` (two separately-quoted, comma-
   separated arguments, actually the more natural convention for a multi-argument call). The correct
   fix (`tools.py`'s `clean_arg()`/`split_args()`) cleans quote characters from each *final* token
   independently, after any comma-splitting, handling both real conventions correctly.

This is unlike the predecessor Cradle PoC, which shipped six real bugs of its own — Threshold
carried forward every one of Cradle's lessons correctly from the start (the corrected guardrail
order, the stale-run reaper, consistent step numbering, the Final Answer streaming-text clearing)
without reproducing any of them. See `../debug/README.md` for the full accounting.

## A real finding that is not a product bug

Repeated rapid `verify_e2e.sh` invocations against the same long-lived container (rebuilding the
image but not the volumes between attempts) eventually exhausted the in-memory rate limiter's
60-second window and left one stale `BLOCKED_PERMISSION` artifact from an earlier debugging attempt
— both expected behaviors of real, persistent, single-process state, not defects. A full clean
rebuild reset everything and the same 26/26 suite passed cleanly on the very next attempt. See
`../debug/README.md`.
