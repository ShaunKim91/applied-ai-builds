## 코드 버그가 아닌 실제 발견 사항

- **로컬 0.5B 모델은 시스템 프롬프트가 클레임마다 하나씩 요구함에도 불구하고, 리서치 보고서에
  인라인 `[n]` 인용 마커를 항상 포함하지는 않습니다.** 포함하지 않을 경우 인용 구조 검사는
  (검사할 무효한 대상이 없으므로) 자명하게 통과하고, 콘텐츠 유사도 기반 근거성 검사도 여전히
  100%로 정당하게 통과할 수 있습니다 — 답변이 문장 단위로 눈에 보이게 인용하지 않으면서도
  실질적으로는 정확하고 근거에 부합할 수 있다는 뜻입니다. 캡처된 스크린샷
  (`docs/screenshots/02-research.png`)에서 직접 관측되었습니다. 이는 근거성/인용 검사 코드
  자체의 결함이 아니라 매우 작은(0.5B 파라미터) 로컬 모델의 알려진 지시 이행 한계이며,
  조용히 넘어가지 않고 `docs/guide.html`의 Known Limitations 섹션에 정직하게 문서화했습니다.
