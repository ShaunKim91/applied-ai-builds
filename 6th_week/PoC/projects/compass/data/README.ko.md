Week4 "Lucent" PoC(부트스트랩 시 고정된 문서 코퍼스를 다운로드해 인덱싱)와 달리, Compass는 정적

(리서치 세션, 리포트, 감사 로그, 예산 설정)와 Chroma 벡터 스토어(과거 리포트 아카이브
인덱스). 둘 다 최초 부팅 시 새로 생성되며 gitignore 대상입니다.
