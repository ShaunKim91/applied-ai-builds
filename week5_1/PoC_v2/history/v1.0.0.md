## The three real bugs found and fixed this build

See `../debug/README.md` for full write-ups, all found via manual (Playwright) screenshot inspection
and direct model measurement, not automated E2E:

1. **A real, measured false-positive in fraud-signal detection**: the embedding-similarity fallback
   scored 0.74–0.82 cosine similarity for a completely unrelated question against every fraud
   pattern — no threshold separates real matches from noise for this embedding model on this
   domain. Fixed by reverting to keyword-only matching.
2. **A real, measured gap in groundedness scoring**: a hallucinated real-world entity ("The Federal
   Insurance Office") that appears in none of the fictional sources scored a perfect 1.0
   groundedness. Partially mitigated with a deterministic entity cross-check — honestly disclosed as
   incomplete, not a full fix.
3. **A latent race condition** in the Research page's entry-loading logic that could, in principle,
   let a stale background fetch silently overwrite a just-completed answer. Fixed structurally by
   removing the redundant automatic fetch.

## Two non-bug findings in the screenshot-testing tooling itself

Documented transparently in `../debug/README.md`: a Playwright actionability-retry quirk on a
button that disables itself synchronously on click (fixed with `{ force: true }`), and — more
consequential — `page.waitForResponse()` resolving on a streaming response's headers rather than its
full body, which produced a confusing cascading failure across two consecutive script steps before
being correctly diagnosed and fixed by waiting on an actual UI completion signal instead.

session's bootstrap checks (real Bing search responses observed, 200 OK).
