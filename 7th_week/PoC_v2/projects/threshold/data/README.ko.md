# data/

레포지토리 안에서는 비어 있습니다 — Docker 볼륨 `threshold_data` 안에서 런타임에 채워집니다:

- `app.db` — SQLite 데이터베이스(조직, 사용자, 리프레시 토큰, 에이전트 실행/스텝, 승인 요청, 안전장치/예산 설정, 해시 체인 기반 감사 로그, 오류 로그)
- `chroma/` — Chroma `PersistentClient` 벡터 스토어(History 시맨틱 검색을 위한 과거 실행 임베딩)

이번 라운드의 Threshold는 정적 시드 코퍼스가 없습니다 — 유일한 "세계"는 작고 고정된 로컬 Python
도구 함수 세트(클레임 조회, 지급액 계산, 통화 변환, 절차 조회)뿐이며, 어느 것도 사전 인덱싱이
필요하지 않습니다.
